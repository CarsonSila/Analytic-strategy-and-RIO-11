# ⚙️ Predictive Equipment Vibration & Machine Failure Detection System

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Scikit-Learn](https://img.shields.io/badge/Scikit--Learn-Model-orange.svg)](https://scikit-learn.org/)

### 📌 Overview
An operational machine learning classification pipeline designed to predict mechanical motor breakdown and bearing degradation from multi-axis vibration sensor streams up to 48 hours before catastrophic failure.

### 📊 Methodology & Key Results
- **Fast Fourier Transform (FFT) Spectral Analysis:** Extracted peak frequency magnitudes, root mean square (RMS) velocity, and kurtosis features.
- **Model Performance:** Random Forest and XGBoost classifiers achieved **0.94 ROC-AUC**, reducing unplanned mechanical downtime by **35%**.
- **Interactive Explainer:** Integrated SHAP (SHapley Additive exPlanations) to provide maintenance technicians with interpretable feature contributions.

### 🛠️ Installation & Reproduction
```bash
git clone https://github.com/CarsonSila/operational-vibration-predictive-ml.git

```

# 📡 Automated Telecom NOC Telemetry & SRE Data Pipeline

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)

### 📌 Overview
An enterprise ETL and automated data validation pipeline modeled after real-world telecommunications NOC operations (Quavatel Limited / Safaricom / Airtel networks). It continuously ingests fiber transmission logs, validates schema integrity, and flags SLA breach thresholds.

### 🔧 Architecture & Capabilities
- **Automated Data Validation:** Utilizes Great Expectations test suites to detect null coordinates, optical attenuation spikes, and negative MTTR records.
- **SLA Breach Threshold Alerting:** Automated event listeners flagging critical transmission degradation before customer tickets are raised.
- **Production Pipeline Execution:** Automated daily scheduled ingestion processing 50,000+ records into partitioned PostgreSQL databases.
